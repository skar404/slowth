კონფიდენციალურობის პოლიტიკა

ბოლოს განახლდა: 2026 წლის 20 სექტემბერი

Slowth არ აგროვებს თქვენი დათვალიერების ისტორიას ან ეკრანის შინაარსს. App Store აპს არ აქვს ანგარიში, ანალიტიკა, თვალყურის დევნება, სარეკლამო SDK ან დეველოპერების მიერ მართული backend. დაბლოკვა და ეკრანის ანალიზი მუშაობს თქვენს მოწყობილობაზე.

Safari დაბლოკვა

Slowth არის Safari გაფართოება თანმხლები აპით iPhone, iPad და Mac. ის კითხულობს მხარდაჭერილ გვერდებს ადგილობრივად, რათა დამალოს ან გადამისამართოს კონტენტი, რომლის დაბლოკვასაც აირჩევთ. დათვალიერების ისტორია, გვერდის კონტენტი და დაბლოკვის არჩევანი არ ეგზავნება დეველოპერს.

რეალურ დროში ბლოკირება (ბეტა) — iPhone და iPad

თუ ჩართავთ ამ არასავალდებულო ფუნქციას, Apple-ის ReplayKit აწვდის ეკრანის ჩარჩოებს, სანამ მაუწყებლობა აქტიურია. Slowth იყენებს Core ML თქვენს მოწყობილობაზე, რათა აღმოაჩინოს არჩეული Shorts, Reels ან Stories და სთხოვს iOS აჩვენოს Screen Time ფარი. სისტემის ჩაწერის ინდიკატორი რჩება ხილული, სანამ მონიტორინგი აქტიურია.

App Store აპის ნორმალური გამოყენებისას ეკრანის ჩარჩოები არ ინახება ან იტვირთება. აუდიო ნიმუშები არ არის დამუშავებული. თქვენ შეგიძლიათ შეწყვიტოთ მონიტორინგი ჩაწერის კონტროლის გამოყენებით. დეველოპერის აღბეჭდვისა და ატვირთვის ხელსაწყოები შეზღუდულია გამართვის კონსტრუქციებით და არ არის ხელმისაწვდომი App Store აპში.

Mac-ზე, Slowth ბლოკავს კონტენტს მხოლოდ Safari-ში; ის არ აკონტროლებს ეკრანს და არ ბლოკავს კონტენტს სხვა აპებში.

რაც რჩება თქვენს მოწყობილობაზე

პარამეტრები, თითო საიტის რეჟიმები, მკაცრი რეჟიმის ტაიმერი, აპების შერჩევის ნიშნები და ადგილობრივი მუშაობის სტატუსი ინახება თქვენს მოწყობილობაზე. ჩამოტვირთული დაბლოკვის წესები ინახება ადგილობრივად. ეს პარამეტრები და წესები არ ეგზავნება დეველოპერს.

წესების განახლებები და ქსელის მოთხოვნები

Safari გაფართოება პერიოდულად ჩამოტვირთავს საჯარო დაბლოკვის წესის ფაილს GitHub Gist-დან HTTPS-ით. იგივე წესები ყველასთვის ხელმისაწვდომია. მოთხოვნა არ შეიცავს დათვალიერების ისტორიას, გვერდის შინაარსს, ეკრანის ჩარჩოებს ან თქვენი აპის არჩევანს.

GitHub იღებს ჩვეულებრივი კავშირის ინფორმაციას, როგორიცაა თქვენი IP მისამართი, ფაილის სერვისის დროს. მოქმედებს მისი კონფიდენციალურობის პოლიტიკა.

Screen Time და Family Controls — მხოლოდ iOS

თქვენი ნებართვით, Slowth იყენებს Apple-ის Family Controls და Managed Settings ჩარჩოებს არჩეული აპების დასაბლოკად. თქვენი არჩევანი წარმოდგენილია კონფიდენციალურობით დაცული ტოკენებით, რომლებიც ინახება ადგილობრივად და გამოიყენება iOS-ს აპების დაბლოკვის გამოყენების თხოვნით.

ვებსაიტი და გარე სერვისები

Slowth ვებსაიტს ემსახურება GitHub გვერდები და Cloudflare. მისი მონახულება ქმნის ჩვეულებრივ ვებ მოთხოვნებს, ამიტომ ეს პროვაიდერები იღებენ კავშირის ინფორმაციას, როგორიცაა თქვენი IP მისამართი. სხვა გარე ბმულების გახსნა რეგულირდება დანიშნულების ადგილის კონფიდენციალურობის პოლიტიკით. ამ გვერდზე ენობრივი ბმულები მუშაობს ქუქიების ან JavaScript-ის გარეშე.

ბავშვები

Slowth არ აგროვებს დათვალიერების ისტორიას ან ეკრანის კონტენტს მომხმარებლებისგან, მათ შორის ბავშვებისგან.

ცვლილებები ამ პოლიტიკაში

თუ ეს პოლიტიკა შეიცვლება, ზედა თარიღი განახლდება. მატერიალური ცვლილებები ასევე აღწერილი იქნება აპლიკაციის გამოშვების შენიშვნებში.

კონტაქტი

კონფიდენციალურობის შესახებ კითხვების ან მოთხოვნებისთვის მოგვწერეთ ელ.წერილი. თუ დაგვიკავშირდებით, ჩვენ ვიღებთ თქვენს ელ. ფოსტის მისამართს და თქვენს მიერ გამოგზავნილ ინფორმაციას, რათა გამოგვეხმაუროთ.
