ગોપનીયતા નીતિ

છેલ્લું અપડેટ: 20 સપ્ટેમ્બર 2026

Slowth તમારો બ્રાઉઝિંગ ઇતિહાસ અથવા સ્ક્રીન સામગ્રી એકત્રિત કરતું નથી. App Store એપ્લિકેશનમાં કોઈ એકાઉન્ટ, એનાલિટિક્સ, ટ્રેકિંગ, જાહેરાત SDK અથવા ડેવલપર દ્વારા સંચાલિત બેકએન્ડ નથી. બ્લોકીંગ અને સ્ક્રીન વિશ્લેષણ તમારા ઉપકરણ પર ચાલે છે.

Safari બ્લોકીંગ

Slowth એ iPhone, iPad અને Mac માટે સાથી એપ્લિકેશન સાથેનું Safari એક્સ્ટેંશન છે. તમે જે સામગ્રીને અવરોધિત કરવાનું પસંદ કરો છો તેને છુપાવવા અથવા રીડાયરેક્ટ કરવા માટે તે સ્થાનિક રીતે સમર્થિત પૃષ્ઠોને વાંચે છે. બ્રાઉઝિંગ ઇતિહાસ, પૃષ્ઠ સામગ્રી અને અવરોધિત પસંદગીઓ વિકાસકર્તાને મોકલવામાં આવતી નથી.

રીઅલ-ટાઇમ બ્લોકીંગ (બીટા) — iPhone અને iPad

જો તમે આ વૈકલ્પિક સુવિધાને સક્ષમ કરો છો, તો Appleનું ReplayKit પ્રસારણ સક્રિય હોય ત્યારે સ્ક્રીન ફ્રેમ્સ પૂરા પાડે છે. Slowth પસંદ કરેલ Shorts, Reels, અથવા વાર્તાઓ શોધવા માટે તમારા ઉપકરણ પર Core ML નો ઉપયોગ કરે છે અને iOS ને Screen Time શિલ્ડ બતાવવા માટે કહે છે. મોનિટરિંગ સક્રિય હોય ત્યારે સિસ્ટમ રેકોર્ડિંગ સૂચક દૃશ્યમાન રહે છે.

App Store એપ્લિકેશનના સામાન્ય ઉપયોગ દરમિયાન સ્ક્રીન ફ્રેમ્સ સાચવવામાં આવતી નથી અથવા અપલોડ થતી નથી. ઑડિઓ નમૂનાઓ પર પ્રક્રિયા કરવામાં આવતી નથી. તમે રેકોર્ડિંગ કંટ્રોલનો ઉપયોગ કરીને મોનિટરિંગ બંધ કરી શકો છો. ડેવલપર કેપ્ચર અને અપલોડ ટૂલ્સ ડીબગ બિલ્ડ્સ માટે પ્રતિબંધિત છે અને App Store એપ્લિકેશનમાં ઉપલબ્ધ નથી.

Mac પર, Slowth માત્ર Safari માં સામગ્રીને અવરોધિત કરે છે; તે સ્ક્રીનને મોનિટર કરતું નથી અથવા અન્ય એપ્લિકેશન્સની અંદરની સામગ્રીને અવરોધિત કરતું નથી.

તમારા ઉપકરણ પર શું રહે છે

સેટિંગ્સ, પ્રતિ-સાઇટ મોડ્સ, સખત મોડ ટાઈમર, એપ્લિકેશન-પસંદગી ટોકન્સ અને સ્થાનિક ઓપરેટિંગ સ્થિતિ તમારા ઉપકરણ પર સંગ્રહિત છે. ડાઉનલોડ કરેલ અવરોધિત નિયમો સ્થાનિક રીતે કેશ કરવામાં આવે છે. આ સેટિંગ્સ અને નિયમો વિકાસકર્તાને મોકલવામાં આવતા નથી.

નિયમ અપડેટ્સ અને નેટવર્ક વિનંતીઓ

Safari એક્સ્ટેંશન સમયાંતરે HTTPS પર GitHub Gist માંથી જાહેર બ્લોકિંગ-રૂલ ફાઇલ ડાઉનલોડ કરે છે. સમાન નિયમો દરેક માટે ઉપલબ્ધ છે. વિનંતીમાં બ્રાઉઝિંગ ઇતિહાસ, પૃષ્ઠ સામગ્રી, સ્ક્રીન ફ્રેમ્સ અથવા તમારી એપ્લિકેશન પસંદગીઓનો સમાવેશ થતો નથી.

GitHub ફાઇલને સર્વ કરતી વખતે સામાન્ય કનેક્શન માહિતી મેળવે છે, જેમ કે તમારું IP સરનામું. તેની પોતાની ગોપનીયતા નીતિ લાગુ પડે છે.

Screen Time અને Family Controls — માત્ર iOS

તમારી પરવાનગી સાથે, Slowth પસંદ કરેલી એપ્સને બ્લોક કરવા માટે Appleના Family Controls અને Managed Settings ફ્રેમવર્કનો ઉપયોગ કરે છે. તમારી પસંદગીઓ ગોપનીયતા-સંરક્ષિત ટોકન્સ દ્વારા દર્શાવવામાં આવે છે, સ્થાનિક રીતે સંગ્રહિત થાય છે અને iOS ને એપ્લિકેશન બ્લોકિંગ લાગુ કરવા માટે કહેવામાં આવે છે.

વેબસાઇટ અને બાહ્ય સેવાઓ

Slowth વેબસાઇટ GitHub પૃષ્ઠો અને Cloudflare દ્વારા સેવા આપવામાં આવે છે. તેની મુલાકાત લેવાથી સામાન્ય વેબ વિનંતીઓ બને છે, તેથી તે પ્રદાતાઓ કનેક્શન માહિતી મેળવે છે જેમ કે તમારું IP સરનામું. અન્ય બાહ્ય લિંક્સ ખોલવાનું ગંતવ્ય સ્થાનની ગોપનીયતા નીતિ દ્વારા સંચાલિત થાય છે. આ પૃષ્ઠ પરની ભાષા લિંક્સ કૂકીઝ અથવા જાવાસ્ક્રિપ્ટ વિના કાર્ય કરે છે.

બાળકો

Slowth બાળકો સહિત વપરાશકર્તાઓ પાસેથી બ્રાઉઝિંગ ઇતિહાસ અથવા સ્ક્રીન સામગ્રી એકત્રિત કરતું નથી.

આ નીતિમાં ફેરફારો

જો આ નીતિ બદલાય છે, તો ટોચ પરની તારીખ અપડેટ કરવામાં આવશે. સામગ્રી ફેરફારો પણ એપ્લિકેશન પ્રકાશન નોંધો માં વર્ણવવામાં આવશે.

  • GitHub ગોપનીયતા નિવેદન
  • Cloudflare ગોપનીયતા નીતિ

સંપર્ક

ગોપનીયતા પ્રશ્નો અથવા વિનંતીઓ માટે, અમને ઇમેઇલ કરો. જો તમે અમારો સંપર્ક કરો છો, તો અમને તમારું ઇમેઇલ સરનામું અને તમે મોકલેલી માહિતી પ્રાપ્ત થશે જેથી અમે પ્રતિસાદ આપી શકીએ.
