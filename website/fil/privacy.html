Patakaran sa Privacy

Huling na-update: 20 Setyembre 2026

Hindi kinokolekta ng Slowth ang iyong history ng pagba-browse o nilalaman ng screen. Ang App Store app ay walang account, analytics, tracking, advertising SDK, o backend na pinapatakbo ng developer. Ang pag-block at pagsusuri sa screen ay tumatakbo sa iyong device.

Pag-block ng Safari

Ang Slowth ay isang Safari extension na may kasamang app para sa iPhone, iPad, at Mac. Nagbabasa ito ng mga sinusuportahang pahina nang lokal upang itago o i-redirect ang nilalaman na pinili mong i-block. Ang kasaysayan ng pagba-browse, nilalaman ng pahina, at mga pagpipilian sa pag-block ay hindi ipinadala sa developer.

Real-time na Pag-block (Beta) — iPhone at iPad

Kung pinagana mo ang opsyonal na feature na ito, ang ReplayKit ng Apple ay nagbibigay ng mga screen frame habang aktibo ang broadcast. Gumagamit ang Slowth ng Core ML sa iyong device para makita ang mga napiling Shorts, Reels, o Stories at hinihiling sa iOS na magpakita ng Screen Time shield. Nananatiling nakikita ang indicator ng pag-record ng system habang aktibo ang pagsubaybay.

Ang mga screen frame ay hindi nai-save o ina-upload sa panahon ng normal na paggamit ng App Store app. Hindi pinoproseso ang mga sample ng audio. Maaari mong ihinto ang pagsubaybay gamit ang mga kontrol sa pag-record. Ang mga tool sa pagkuha at pag-upload ng developer ay pinaghihigpitan sa pag-debug ng mga build at hindi available sa App Store app.

Sa Mac, hinaharangan ng Slowth ang nilalaman lamang sa Safari ; hindi nito sinusubaybayan ang screen o hinaharangan ang nilalaman sa loob ng iba pang mga app.

Ano ang nananatili sa iyong device

Ang mga setting, bawat-site na mode, timer ng Strict Mode, mga token sa pagpili ng app, at lokal na katayuan sa pagpapatakbo ay naka-imbak sa iyong device. Lokal na naka-cache ang mga na-download na panuntunan sa pag-block. Ang mga setting at panuntunang ito ay hindi ipinadala sa developer.

Mga update sa panuntunan at mga kahilingan sa network

Pana-panahong nagda-download ang extension ng Safari ng pampublikong blocking-rule file mula sa GitHub Gist sa HTTPS. Ang parehong mga patakaran ay magagamit sa lahat. Ang kahilingan ay hindi kasama ang kasaysayan ng pagba-browse, nilalaman ng pahina, mga frame ng screen, o mga pagpipilian ng iyong app.

Tumatanggap ang GitHub ng ordinaryong impormasyon sa koneksyon, gaya ng iyong IP address, kapag inihahatid ang file. Nalalapat ang sarili nitong patakaran sa privacy.

Screen Time at Family Controls — iOS lang

Sa iyong pahintulot, ginagamit ng Slowth ang mga framework ng Family Controls at Managed Settings ng Apple upang harangan ang mga napiling app. Ang iyong mga pinili ay kinakatawan ng mga token na protektado ng privacy, na lokal na nakaimbak at ginagamit upang hilingin sa iOS na ilapat ang pag-block ng app.

Website at mga panlabas na serbisyo

Ang website ng Slowth ay inihahatid sa pamamagitan ng GitHub Pages at Cloudflare. Ang pagbisita dito ay lumilikha ng mga ordinaryong kahilingan sa web, kaya ang mga provider na iyon ay tumatanggap ng impormasyon ng koneksyon gaya ng iyong IP address. Ang pagbubukas ng iba pang mga panlabas na link ay pinamamahalaan ng patakaran sa privacy ng destinasyon. Gumagana ang mga link ng wika sa page na ito nang walang cookies o JavaScript.

Mga bata

Ang Slowth ay hindi nangongolekta ng kasaysayan ng pagba-browse o nilalaman ng screen mula sa mga user, kabilang ang mga bata.

Mga pagbabago sa patakarang ito

Kung magbabago ang patakarang ito, maa-update ang petsa sa itaas. Ang mga pagbabago sa materyal ay ilalarawan din sa mga tala sa paglabas ng app.
