隐私政策

最后更新：2026 年 9 月 20 日

Slowth 不会收集您的浏览历史记录或屏幕内容。 App Store 应用程序没有帐户、分析、跟踪、广告 SDK 或开发人员操作的后端。阻止和屏幕分析在您的设备上运行。

Safari 封锁

Slowth 是 Safari 扩展，带有适用于 iPhone 、 iPad 和 Mac 的配套应用程序。它在本地读取支持的页面以隐藏或重定向您选择阻止的内容。浏览历史记录、页面内容和阻止选择不会发送给开发人员。

实时阻止（测试版）— iPhone 和 iPad

如果启用此可选功能，Apple 的 ReplayKit 将在广播活动时提供屏幕帧。 Slowth 在您的设备上使用 Core ML 来检测选定的 Shorts 、 Reels 或故事，并要求 iOS 显示 屏幕使用时间 盾牌。当监控处于活动状态时，系统记录指示器保持可见。

在正常使用 App Store 应用程序期间，不会保存或上传屏幕帧。音频样本未经过处理。您可以使用录制控件停止监视。开发人员捕获和上传工具仅限于调试版本，并且在 App Store 应用程序中不可用。

在 Mac 上，Slowth 仅阻止 Safari 中的内容；它不会监视屏幕或阻止其他应用程序内的内容。

您的设备上保留的内容

设置、每个站点模式、严格模式计时器、应用程序选择令牌和本地操作状态都存储在您的设备上。下载的阻止规则缓存在本地。这些设置和规则不会发送给开发人员。

规则更新和网络请求

Safari 扩展定期通过 HTTPS 从 GitHub Gist 下载公共阻止规则文件。每个人都可以使用相同的规则。该请求不包括浏览历史记录、页面内容、屏幕框架或您的应用程序选择。

GitHub 在提供文件时接收普通连接信息，例如您的 IP 地址。适用其自己的隐私政策。

屏幕使用时间 和 Family Controls — 仅 iOS

经您许可，Slowth 使用 Apple 的 Family Controls 和 Managed Settings 框架来阻止选定的应用程序。您的选择由受隐私保护的令牌表示，存储在本地并用于要求 iOS 应用应用程序阻止。

网站和外部服务

Slowth 网站通过 GitHub 页面和 Cloudflare 提供服务。访问它会创建普通的 Web 请求，因此这些提供商会收到连接信息，例如您的 IP 地址。打开其他外部链接受目的地隐私政策的约束。此页面上的语言链接无需 cookie 或 JavaScript 即可运行。

孩子们

Slowth 不会收集用户（包括儿童）的浏览历史记录或屏幕内容。

本政策的变更

如果此政策发生变化，顶部的日期将会更新。应用程序发行说明中还将描述重大更改。
