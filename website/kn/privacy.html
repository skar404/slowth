ಗೌಪ್ಯತಾ ನೀತಿ

ಕೊನೆಯದಾಗಿ ನವೀಕರಿಸಲಾಗಿದೆ: 20 ಸೆಪ್ಟೆಂಬರ್ 2026

Slowth ನಿಮ್ಮ ಬ್ರೌಸಿಂಗ್ ಇತಿಹಾಸ ಅಥವಾ ಪರದೆಯ ವಿಷಯವನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ. App Store ಅಪ್ಲಿಕೇಶನ್ ಯಾವುದೇ ಖಾತೆ, ವಿಶ್ಲೇಷಣೆ, ಟ್ರ್ಯಾಕಿಂಗ್, ಜಾಹೀರಾತು SDK ಅಥವಾ ಡೆವಲಪರ್-ಚಾಲಿತ ಬ್ಯಾಕೆಂಡ್ ಅನ್ನು ಹೊಂದಿಲ್ಲ. ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ನಿರ್ಬಂಧಿಸುವಿಕೆ ಮತ್ತು ಪರದೆಯ ವಿಶ್ಲೇಷಣೆ ರನ್ ಆಗುತ್ತದೆ.

Safari ನಿರ್ಬಂಧಿಸುವುದು

Slowth iPhone, iPad, ಮತ್ತು Mac ಗಾಗಿ ಕಂಪ್ಯಾನಿಯನ್ ಅಪ್ಲಿಕೇಶನ್‌ನೊಂದಿಗೆ Safari ವಿಸ್ತರಣೆಯಾಗಿದೆ. ನೀವು ನಿರ್ಬಂಧಿಸಲು ಆಯ್ಕೆಮಾಡಿದ ವಿಷಯವನ್ನು ಮರೆಮಾಡಲು ಅಥವಾ ಮರುನಿರ್ದೇಶಿಸಲು ಇದು ಸ್ಥಳೀಯವಾಗಿ ಬೆಂಬಲಿತ ಪುಟಗಳನ್ನು ಓದುತ್ತದೆ. ಬ್ರೌಸಿಂಗ್ ಇತಿಹಾಸ, ಪುಟದ ವಿಷಯ ಮತ್ತು ನಿರ್ಬಂಧಿಸುವ ಆಯ್ಕೆಗಳನ್ನು ಡೆವಲಪರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.

ರಿಯಲ್-ಟೈಮ್ ಬ್ಲಾಕಿಂಗ್ (ಬೀಟಾ) — iPhone ಮತ್ತು iPad

ನೀವು ಈ ಐಚ್ಛಿಕ ವೈಶಿಷ್ಟ್ಯವನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿದರೆ, ಪ್ರಸಾರವು ಸಕ್ರಿಯವಾಗಿರುವಾಗ Apple ನ ReplayKit ಪರದೆಯ ಚೌಕಟ್ಟುಗಳನ್ನು ಪೂರೈಸುತ್ತದೆ. Slowth ಆಯ್ಕೆಮಾಡಿದ Shorts, Reels, ಅಥವಾ ಕಥೆಗಳನ್ನು ಪತ್ತೆಹಚ್ಚಲು ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ Core ML ಅನ್ನು ಬಳಸುತ್ತದೆ ಮತ್ತು Screen Time ಶೀಲ್ಡ್ ಅನ್ನು ತೋರಿಸಲು iOS ಅನ್ನು ಕೇಳುತ್ತದೆ. ಮೇಲ್ವಿಚಾರಣೆಯು ಸಕ್ರಿಯವಾಗಿರುವಾಗ ಸಿಸ್ಟಮ್ ರೆಕಾರ್ಡಿಂಗ್ ಸೂಚಕವು ಗೋಚರಿಸುತ್ತದೆ.

App Store ಅಪ್ಲಿಕೇಶನ್‌ನ ಸಾಮಾನ್ಯ ಬಳಕೆಯ ಸಮಯದಲ್ಲಿ ಸ್ಕ್ರೀನ್ ಫ್ರೇಮ್‌ಗಳನ್ನು ಉಳಿಸಲಾಗುವುದಿಲ್ಲ ಅಥವಾ ಅಪ್‌ಲೋಡ್ ಮಾಡಲಾಗುವುದಿಲ್ಲ. ಆಡಿಯೋ ಮಾದರಿಗಳನ್ನು ಪ್ರಕ್ರಿಯೆಗೊಳಿಸಲಾಗಿಲ್ಲ. ರೆಕಾರ್ಡಿಂಗ್ ನಿಯಂತ್ರಣಗಳನ್ನು ಬಳಸಿಕೊಂಡು ನೀವು ಮೇಲ್ವಿಚಾರಣೆಯನ್ನು ನಿಲ್ಲಿಸಬಹುದು. ಡೆವಲಪರ್ ಕ್ಯಾಪ್ಚರ್ ಮತ್ತು ಅಪ್‌ಲೋಡ್ ಪರಿಕರಗಳನ್ನು ಡೀಬಗ್ ಬಿಲ್ಡ್‌ಗಳಿಗೆ ನಿರ್ಬಂಧಿಸಲಾಗಿದೆ ಮತ್ತು App Store ಅಪ್ಲಿಕೇಶನ್‌ನಲ್ಲಿ ಲಭ್ಯವಿಲ್ಲ.

Mac ನಲ್ಲಿ, Slowth Safari ನಲ್ಲಿ ಮಾತ್ರ ವಿಷಯವನ್ನು ನಿರ್ಬಂಧಿಸುತ್ತದೆ; ಇದು ಪರದೆಯನ್ನು ಮೇಲ್ವಿಚಾರಣೆ ಮಾಡುವುದಿಲ್ಲ ಅಥವಾ ಇತರ ಅಪ್ಲಿಕೇಶನ್‌ಗಳಲ್ಲಿ ವಿಷಯವನ್ನು ನಿರ್ಬಂಧಿಸುವುದಿಲ್ಲ.

ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಏನು ಉಳಿಯುತ್ತದೆ

ಸೆಟ್ಟಿಂಗ್‌ಗಳು, ಪ್ರತಿ-ಸೈಟ್ ಮೋಡ್‌ಗಳು, ಕಟ್ಟುನಿಟ್ಟಾದ ಮೋಡ್ ಟೈಮರ್, ಅಪ್ಲಿಕೇಶನ್-ಆಯ್ಕೆ ಟೋಕನ್‌ಗಳು ಮತ್ತು ಸ್ಥಳೀಯ ಆಪರೇಟಿಂಗ್ ಸ್ಥಿತಿಯನ್ನು ನಿಮ್ಮ ಸಾಧನದಲ್ಲಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ. ಡೌನ್‌ಲೋಡ್ ಮಾಡಲಾದ ನಿರ್ಬಂಧಿಸುವ ನಿಯಮಗಳನ್ನು ಸ್ಥಳೀಯವಾಗಿ ಸಂಗ್ರಹಿಸಲಾಗಿದೆ. ಈ ಸೆಟ್ಟಿಂಗ್‌ಗಳು ಮತ್ತು ನಿಯಮಗಳನ್ನು ಡೆವಲಪರ್‌ಗೆ ಕಳುಹಿಸಲಾಗುವುದಿಲ್ಲ.

ನಿಯಮ ನವೀಕರಣಗಳು ಮತ್ತು ನೆಟ್‌ವರ್ಕ್ ವಿನಂತಿಗಳು

Safari ವಿಸ್ತರಣೆಯು ನಿಯತಕಾಲಿಕವಾಗಿ HTTPS ಮೂಲಕ GitHub ಜಿಸ್ಟ್‌ನಿಂದ ಸಾರ್ವಜನಿಕ ನಿರ್ಬಂಧಿಸುವ-ನಿಯಮ ಫೈಲ್ ಅನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ. ಅದೇ ನಿಯಮಗಳು ಎಲ್ಲರಿಗೂ ಲಭ್ಯವಿದೆ. ವಿನಂತಿಯು ಬ್ರೌಸಿಂಗ್ ಇತಿಹಾಸ, ಪುಟದ ವಿಷಯ, ಪರದೆಯ ಚೌಕಟ್ಟುಗಳು ಅಥವಾ ನಿಮ್ಮ ಅಪ್ಲಿಕೇಶನ್ ಆಯ್ಕೆಗಳನ್ನು ಒಳಗೊಂಡಿಲ್ಲ.

GitHub ಫೈಲ್ ಅನ್ನು ಪೂರೈಸುವಾಗ ನಿಮ್ಮ IP ವಿಳಾಸದಂತಹ ಸಾಮಾನ್ಯ ಸಂಪರ್ಕ ಮಾಹಿತಿಯನ್ನು ಪಡೆಯುತ್ತದೆ. ಅದರ ಸ್ವಂತ ಗೌಪ್ಯತೆ ನೀತಿ ಅನ್ವಯಿಸುತ್ತದೆ.

Screen Time ಮತ್ತು Family Controls — iOS ಮಾತ್ರ

ನಿಮ್ಮ ಅನುಮತಿಯೊಂದಿಗೆ, ಆಯ್ದ ಅಪ್ಲಿಕೇಶನ್‌ಗಳನ್ನು ನಿರ್ಬಂಧಿಸಲು Slowth Apple ನ Family Controls ಮತ್ತು Managed Settings ಫ್ರೇಮ್‌ವರ್ಕ್‌ಗಳನ್ನು ಬಳಸುತ್ತದೆ. ನಿಮ್ಮ ಆಯ್ಕೆಗಳನ್ನು ಗೌಪ್ಯತೆ-ರಕ್ಷಿತ ಟೋಕನ್‌ಗಳಿಂದ ಪ್ರತಿನಿಧಿಸಲಾಗುತ್ತದೆ, ಸ್ಥಳೀಯವಾಗಿ ಸಂಗ್ರಹಿಸಲಾಗುತ್ತದೆ ಮತ್ತು ಅಪ್ಲಿಕೇಶನ್ ನಿರ್ಬಂಧಿಸುವಿಕೆಯನ್ನು ಅನ್ವಯಿಸಲು iOS ಅನ್ನು ಕೇಳಲು ಬಳಸಲಾಗುತ್ತದೆ.

ವೆಬ್‌ಸೈಟ್ ಮತ್ತು ಬಾಹ್ಯ ಸೇವೆಗಳು

Slowth ವೆಬ್‌ಸೈಟ್ ಅನ್ನು GitHub ಪುಟಗಳು ಮತ್ತು Cloudflare ಮೂಲಕ ನೀಡಲಾಗುತ್ತದೆ. ಇದನ್ನು ಭೇಟಿ ಮಾಡುವುದರಿಂದ ಸಾಮಾನ್ಯ ವೆಬ್ ವಿನಂತಿಗಳನ್ನು ರಚಿಸಲಾಗುತ್ತದೆ, ಆದ್ದರಿಂದ ಆ ಪೂರೈಕೆದಾರರು ನಿಮ್ಮ IP ವಿಳಾಸದಂತಹ ಸಂಪರ್ಕ ಮಾಹಿತಿಯನ್ನು ಸ್ವೀಕರಿಸುತ್ತಾರೆ. ಇತರ ಬಾಹ್ಯ ಲಿಂಕ್‌ಗಳನ್ನು ತೆರೆಯುವುದು ಗಮ್ಯಸ್ಥಾನದ ಗೌಪ್ಯತೆ ನೀತಿಯಿಂದ ನಿಯಂತ್ರಿಸಲ್ಪಡುತ್ತದೆ. ಈ ಪುಟದಲ್ಲಿನ ಭಾಷಾ ಲಿಂಕ್‌ಗಳು ಕುಕೀಗಳು ಅಥವಾ ಜಾವಾಸ್ಕ್ರಿಪ್ಟ್ ಇಲ್ಲದೆ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತವೆ.

ಮಕ್ಕಳು

Slowth ಮಕ್ಕಳನ್ನು ಒಳಗೊಂಡಂತೆ ಬಳಕೆದಾರರಿಂದ ಬ್ರೌಸಿಂಗ್ ಇತಿಹಾಸ ಅಥವಾ ಪರದೆಯ ವಿಷಯವನ್ನು ಸಂಗ್ರಹಿಸುವುದಿಲ್ಲ.

ಈ ನೀತಿಗೆ ಬದಲಾವಣೆಗಳು

ಈ ನೀತಿಯು ಬದಲಾದರೆ, ಮೇಲ್ಭಾಗದಲ್ಲಿರುವ ದಿನಾಂಕವನ್ನು ನವೀಕರಿಸಲಾಗುತ್ತದೆ. ಅಪ್ಲಿಕೇಶನ್ ಬಿಡುಗಡೆ ಟಿಪ್ಪಣಿಗಳಲ್ಲಿ ವಸ್ತು ಬದಲಾವಣೆಗಳನ್ನು ಸಹ ವಿವರಿಸಲಾಗುತ್ತದೆ.

  • Cloudflare ಗೌಪ್ಯತೆ ನೀತಿ

ಸಂಪರ್ಕ

ಗೌಪ್ಯತೆ ಪ್ರಶ್ನೆಗಳು ಅಥವಾ ವಿನಂತಿಗಳಿಗಾಗಿ, ನಮಗೆ ಇಮೇಲ್ ಮಾಡಿ. ನೀವು ನಮ್ಮನ್ನು ಸಂಪರ್ಕಿಸಿದರೆ, ನಿಮ್ಮ ಇಮೇಲ್ ವಿಳಾಸ ಮತ್ತು ನೀವು ಕಳುಹಿಸುವ ಮಾಹಿತಿಯನ್ನು ನಾವು ಸ್ವೀಕರಿಸುತ್ತೇವೆ ಆದ್ದರಿಂದ ನಾವು ಪ್ರತಿಕ್ರಿಯಿಸಬಹುದು.
