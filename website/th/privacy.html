นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด: 20 กันยายน 2569

Slowth จะไม่รวบรวมประวัติการเรียกดูหรือเนื้อหาบนหน้าจอของคุณ แอป App Store ไม่มีบัญชี การวิเคราะห์ การติดตาม SDK การโฆษณา หรือแบ็กเอนด์ที่ดำเนินการโดยนักพัฒนา การบล็อกและการวิเคราะห์หน้าจอทำงานบนอุปกรณ์ของคุณ

การบล็อก Safari

Slowth เป็นส่วนขยาย Safari พร้อมด้วยแอปที่แสดงร่วมสำหรับ iPhone, iPad และ Mac อ่านหน้าที่รองรับในเครื่องเพื่อซ่อนหรือเปลี่ยนเส้นทางเนื้อหาที่คุณเลือกบล็อก ประวัติการเรียกดู เนื้อหาของหน้า และตัวเลือกการบล็อกจะไม่ถูกส่งไปยังนักพัฒนา

การบล็อกแบบเรียลไทม์ (เบต้า) — iPhone และ iPad

หากคุณเปิดใช้งานคุณสมบัติเสริมนี้ ReplayKit ของ Apple จะให้เฟรมหน้าจอในขณะที่การออกอากาศทำงานอยู่ Slowth ใช้ Core ML บนอุปกรณ์ของคุณเพื่อตรวจจับ Shorts, Reels หรือเรื่องราวที่เลือก และขอให้ iOS แสดงเกราะ Screen Time ตัวบ่งชี้การบันทึกระบบยังคงมองเห็นได้ในขณะที่การตรวจสอบทำงานอยู่

เฟรมหน้าจอไม่ได้รับการบันทึกหรืออัปโหลดระหว่างการใช้งานปกติของแอป App Store ตัวอย่างเสียงไม่ได้รับการประมวลผล คุณสามารถหยุดการตรวจสอบได้โดยใช้ส่วนควบคุมการบันทึก เครื่องมือจับภาพและอัปโหลดของนักพัฒนาถูกจำกัดไว้เฉพาะการแก้ไขข้อบกพร่องเท่านั้น และไม่มีให้บริการในแอป App Store

บน Mac, Slowth บล็อกเนื้อหาเฉพาะใน Safari ; มันไม่ได้ตรวจสอบหน้าจอหรือบล็อกเนื้อหาภายในแอพอื่น

สิ่งที่คงอยู่ในอุปกรณ์ของคุณ

การตั้งค่า, โหมดตามไซต์, ตัวจับเวลาโหมดเข้มงวด, โทเค็นการเลือกแอป และสถานะการทำงานในเครื่องจะถูกจัดเก็บไว้ในอุปกรณ์ของคุณ กฎการบล็อกที่ดาวน์โหลดจะถูกแคชไว้ในเครื่อง การตั้งค่าและกฎเหล่านี้จะไม่ถูกส่งไปยังนักพัฒนา

การอัปเดตกฎและคำขอเครือข่าย

ส่วนขยาย Safari จะดาวน์โหลดไฟล์กฎการบล็อกสาธารณะจาก GitHub Gist ผ่าน HTTPS เป็นระยะ ทุกคนใช้กฎเดียวกันนี้ได้ คำขอไม่รวมถึงประวัติการเรียกดู เนื้อหาของหน้า กรอบหน้าจอ หรือการเลือกแอปของคุณ

GitHub ได้รับข้อมูลการเชื่อมต่อทั่วไป เช่น ที่อยู่ IP ของคุณ เมื่อให้บริการไฟล์ มีการใช้นโยบายความเป็นส่วนตัวของตนเอง

Screen Time และ Family Controls — iOS เท่านั้น

เมื่อได้รับอนุญาตจากคุณ Slowth จะใช้เฟรมเวิร์ก Family Controls และ Managed Settings ของ Apple เพื่อบล็อกแอปที่เลือก การเลือกของคุณจะแสดงด้วยโทเค็นที่มีการป้องกันความเป็นส่วนตัว ซึ่งจัดเก็บไว้ในเครื่องและใช้เพื่อขอให้ iOS ใช้การบล็อกแอป

เว็บไซต์และบริการภายนอก

เว็บไซต์ Slowth ให้บริการผ่านเพจ GitHub และ Cloudflare การเยี่ยมชมเว็บไซต์จะสร้างคำขอทางเว็บตามปกติ ดังนั้นผู้ให้บริการเหล่านั้นจะได้รับข้อมูลการเชื่อมต่อ เช่น ที่อยู่ IP ของคุณ การเปิดลิงก์ภายนอกอื่นๆ จะอยู่ภายใต้นโยบายความเป็นส่วนตัวของปลายทาง ลิงก์ภาษาในหน้านี้ใช้งานได้โดยไม่ต้องใช้คุกกี้หรือ JavaScript

เด็กๆ

Slowth ไม่รวบรวมประวัติการเรียกดูหรือเนื้อหาบนหน้าจอจากผู้ใช้ รวมถึงเด็กๆ ด้วย

การเปลี่ยนแปลงนโยบายนี้

หากนโยบายนี้เปลี่ยนแปลง วันที่ด้านบนจะได้รับการอัปเดต การเปลี่ยนแปลงที่สำคัญจะมีการอธิบายไว้ในบันทึกประจำรุ่นของแอปด้วย

  • คำชี้แจงสิทธิส่วนบุคคล GitHub
  • Cloudflare นโยบายความเป็นส่วนตัว

ติดต่อ
