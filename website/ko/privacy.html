개인정보 보호정책

최종 업데이트 날짜: 2026년 9월 20일

Slowth는 검색 기록이나 화면 콘텐츠를 수집하지 않습니다. App Store 앱에는 계정, 분석, 추적, 광고 SDK 또는 개발자가 운영하는 백엔드가 없습니다. 차단 및 화면 분석은 귀하의 장치에서 실행됩니다.

Safari 차단

Slowth는 iPhone, iPad 및 Mac용 동반 앱이 포함된 Safari 확장입니다. 지원되는 페이지를 로컬에서 읽어 차단하도록 선택한 콘텐츠를 숨기거나 리디렉션합니다. 검색 기록, 페이지 콘텐츠, 차단 선택 사항은 개발자에게 전송되지 않습니다.

실시간 차단(베타) — iPhone 및 iPad

이 옵션 기능을 활성화하면 Apple의 ReplayKit는 방송이 활성화되는 동안 화면 프레임을 제공합니다. Slowth는 기기에서 Core ML를 사용하여 선택한 Shorts, Reels 또는 스토리를 감지하고 iOS에게 스크린 타임 방패를 표시하도록 요청합니다. 모니터링이 활성화되어 있는 동안 시스템 녹화 표시기가 계속 표시됩니다.

App Store 앱을 정상적으로 사용하는 동안에는 화면 프레임이 저장되거나 업로드되지 않습니다. 오디오 샘플은 처리되지 않습니다. 녹음 컨트롤을 사용하여 모니터링을 중지할 수 있습니다. 개발자 캡처 및 업로드 도구는 디버그 빌드로만 제한되며 App Store 앱에서는 사용할 수 없습니다.

Mac 에서 Slowth 는 Safari 의 콘텐츠만 차단합니다. 화면을 모니터링하거나 다른 앱 내부의 콘텐츠를 차단하지 않습니다.

기기에 남아 있는 내용

설정, 사이트별 모드, 엄격 모드 타이머, 앱 선택 토큰 및 로컬 작동 상태가 장치에 저장됩니다. 다운로드한 차단 규칙은 로컬로 캐시됩니다. 이러한 설정과 규칙은 개발자에게 전송되지 않습니다.

규칙 업데이트 및 네트워크 요청

Safari 확장은 HTTPS를 통해 GitHub Gist에서 공개 차단 규칙 파일을 주기적으로 다운로드합니다. 모든 사람에게 동일한 규칙이 적용됩니다. 요청에는 검색 기록, 페이지 콘텐츠, 화면 프레임 또는 앱 선택이 포함되지 않습니다.

GitHub는 파일을 제공할 때 IP 주소와 같은 일반 연결 정보를 받습니다. 자체 개인 정보 보호 정책이 적용됩니다.

스크린 타임 및 Family Controls — iOS에만 해당

귀하의 허락 하에 Slowth는 Apple의 Family Controls 및 Managed Settings 프레임워크를 사용하여 선택된 앱을 차단합니다. 귀하의 선택 사항은 개인 정보 보호 토큰으로 표시되며 로컬에 저장되고 iOS에 앱 차단을 적용하도록 요청하는 데 사용됩니다.

웹사이트 및 외부 서비스

Slowth 웹사이트는 GitHub 페이지 및 Cloudflare를 통해 제공됩니다. 이를 방문하면 일반적인 웹 요청이 생성되므로 해당 공급자는 IP 주소와 같은 연결 정보를 받습니다. 다른 외부 링크를 여는 행위에는 목적지의 개인정보 보호정책이 적용됩니다. 이 페이지의 언어 링크는 쿠키나 JavaScript 없이 작동합니다.

어린이들

Slowth는 어린이를 포함한 사용자로부터 검색 기록이나 화면 콘텐츠를 수집하지 않습니다.
