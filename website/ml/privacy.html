സ്വകാര്യതാ നയം

അവസാനം അപ്ഡേറ്റ് ചെയ്തത്: 20 സെപ്റ്റംബർ 2026

Slowth നിങ്ങളുടെ ബ്രൗസിംഗ് ചരിത്രമോ സ്‌ക്രീൻ ഉള്ളടക്കമോ ശേഖരിക്കുന്നില്ല. App Store ആപ്പിന് അക്കൗണ്ട്, അനലിറ്റിക്‌സ്, ട്രാക്കിംഗ്, പരസ്യം ചെയ്യൽ SDK, അല്ലെങ്കിൽ ഡെവലപ്പർ പ്രവർത്തിപ്പിക്കുന്ന ബാക്കെൻഡ് എന്നിവയില്ല. ബ്ലോക്കിംഗും സ്‌ക്രീൻ വിശകലനവും നിങ്ങളുടെ ഉപകരണത്തിൽ പ്രവർത്തിക്കുന്നു.

Safari തടയൽ

Slowth എന്നത് Safari വിപുലീകരണമാണ്, iPhone, iPad, Mac എന്നിവയ്‌ക്കായുള്ള ഒരു സഹചാരി ആപ്പ്. നിങ്ങൾ തടയാൻ തിരഞ്ഞെടുക്കുന്ന ഉള്ളടക്കം മറയ്‌ക്കാനോ റീഡയറക്‌ടുചെയ്യാനോ ഇത് പിന്തുണയ്‌ക്കുന്ന പേജുകൾ പ്രാദേശികമായി വായിക്കുന്നു. ബ്രൗസിംഗ് ചരിത്രം, പേജ് ഉള്ളടക്കം, തടയൽ ചോയ്‌സുകൾ എന്നിവ ഡെവലപ്പർക്ക് അയയ്‌ക്കില്ല.

തത്സമയ തടയൽ (ബീറ്റ) — iPhone, iPad

നിങ്ങൾ ഈ ഓപ്‌ഷണൽ ഫീച്ചർ പ്രവർത്തനക്ഷമമാക്കുകയാണെങ്കിൽ, ആപ്പിളിൻ്റെ ReplayKit പ്രക്ഷേപണം സജീവമായിരിക്കുമ്പോൾ സ്‌ക്രീൻ ഫ്രെയിമുകൾ നൽകുന്നു. തിരഞ്ഞെടുത്ത Shorts, Reels, അല്ലെങ്കിൽ സ്റ്റോറികൾ കണ്ടെത്തുന്നതിന് Slowth നിങ്ങളുടെ ഉപകരണത്തിൽ Core ML ഉപയോഗിക്കുന്നു കൂടാതെ Screen Time ഷീൽഡ് കാണിക്കാൻ iOS ആവശ്യപ്പെടുന്നു. മോണിറ്ററിംഗ് സജീവമായിരിക്കുമ്പോൾ സിസ്റ്റം റെക്കോർഡിംഗ് സൂചകം ദൃശ്യമാകും.

App Store ആപ്പിൻ്റെ സാധാരണ ഉപയോഗ സമയത്ത് സ്‌ക്രീൻ ഫ്രെയിമുകൾ സംരക്ഷിക്കുകയോ അപ്‌ലോഡ് ചെയ്യുകയോ ചെയ്യുന്നില്ല. ഓഡിയോ സാമ്പിളുകൾ പ്രോസസ്സ് ചെയ്തിട്ടില്ല. റെക്കോർഡിംഗ് നിയന്ത്രണങ്ങൾ ഉപയോഗിച്ച് നിങ്ങൾക്ക് നിരീക്ഷണം നിർത്താം. ഡെവലപ്പർ ക്യാപ്‌ചർ, അപ്‌ലോഡ് ടൂളുകൾ ഡീബഗ് ബിൽഡുകളിലേക്ക് പരിമിതപ്പെടുത്തിയിരിക്കുന്നു, അവ App Store ആപ്പിൽ ലഭ്യമല്ല.

Mac-ൽ, Slowth Safari-ൽ മാത്രം ഉള്ളടക്കം തടയുന്നു; ഇത് സ്‌ക്രീൻ നിരീക്ഷിക്കുകയോ മറ്റ് ആപ്പുകൾക്കുള്ളിലെ ഉള്ളടക്കം തടയുകയോ ചെയ്യുന്നില്ല.

നിങ്ങളുടെ ഉപകരണത്തിൽ എന്താണ് നിലനിൽക്കുന്നത്

ക്രമീകരണങ്ങൾ, ഓരോ സൈറ്റിനും മോഡുകൾ, കർശന മോഡ് ടൈമർ, ആപ്പ്-സെലക്ഷൻ ടോക്കണുകൾ, പ്രാദേശിക പ്രവർത്തന നില എന്നിവ നിങ്ങളുടെ ഉപകരണത്തിൽ സംഭരിച്ചിരിക്കുന്നു. ഡൗൺലോഡ് ചെയ്ത തടയൽ നിയമങ്ങൾ പ്രാദേശികമായി കാഷെ ചെയ്യുന്നു. ഈ ക്രമീകരണങ്ങളും നിയമങ്ങളും ഡെവലപ്പർക്ക് അയച്ചിട്ടില്ല.

റൂൾ അപ്‌ഡേറ്റുകളും നെറ്റ്‌വർക്ക് അഭ്യർത്ഥനകളും

Safari വിപുലീകരണം GitHub Gist-ൽ നിന്ന് HTTPS-ലൂടെ ഒരു പൊതു ബ്ലോക്കിംഗ്-റൂൾ ഫയൽ ആനുകാലികമായി ഡൗൺലോഡ് ചെയ്യുന്നു. എല്ലാവർക്കും ഒരേ നിയമങ്ങൾ ലഭ്യമാണ്. അഭ്യർത്ഥനയിൽ ബ്രൗസിംഗ് ചരിത്രമോ പേജ് ഉള്ളടക്കമോ സ്‌ക്രീൻ ഫ്രെയിമുകളോ നിങ്ങളുടെ ആപ്പ് തിരഞ്ഞെടുക്കലുകളോ ഉൾപ്പെടുന്നില്ല.

ഫയൽ സെർവ് ചെയ്യുമ്പോൾ GitHub നിങ്ങളുടെ IP വിലാസം പോലുള്ള സാധാരണ കണക്ഷൻ വിവരങ്ങൾ സ്വീകരിക്കുന്നു. അതിൻ്റെ സ്വന്തം സ്വകാര്യതാ നയം ബാധകമാണ്.

Screen Time, Family Controls — iOS മാത്രം

നിങ്ങളുടെ അനുമതിയോടെ, തിരഞ്ഞെടുത്ത ആപ്പുകൾ തടയാൻ Slowth Apple-ൻ്റെ Family Controls, Managed Settings ഫ്രെയിംവർക്കുകൾ ഉപയോഗിക്കുന്നു. നിങ്ങളുടെ തിരഞ്ഞെടുക്കലുകൾ സ്വകാര്യത പരിരക്ഷിത ടോക്കണുകളാൽ പ്രതിനിധീകരിക്കപ്പെടുന്നു, പ്രാദേശികമായി സംഭരിക്കുകയും iOS ആപ്പ് തടയൽ പ്രയോഗിക്കാൻ ആവശ്യപ്പെടുകയും ചെയ്യുന്നു.

വെബ്‌സൈറ്റും ബാഹ്യ സേവനങ്ങളും

Slowth വെബ്‌സൈറ്റ് GitHub പേജുകൾ, Cloudflare എന്നിവയിലൂടെയാണ് നൽകുന്നത്. ഇത് സന്ദർശിക്കുന്നത് സാധാരണ വെബ് അഭ്യർത്ഥനകൾ സൃഷ്ടിക്കുന്നു, അതിനാൽ ആ ദാതാക്കൾക്ക് നിങ്ങളുടെ IP വിലാസം പോലുള്ള കണക്ഷൻ വിവരങ്ങൾ ലഭിക്കും. മറ്റ് ബാഹ്യ ലിങ്കുകൾ തുറക്കുന്നത് ലക്ഷ്യസ്ഥാനത്തിൻ്റെ സ്വകാര്യതാ നയമാണ് നിയന്ത്രിക്കുന്നത്. ഈ പേജിലെ ഭാഷാ ലിങ്കുകൾ കുക്കികളോ ജാവാസ്ക്രിപ്റ്റോ ഇല്ലാതെ പ്രവർത്തിക്കുന്നു.

കുട്ടികൾ

Slowth കുട്ടികൾ ഉൾപ്പെടെയുള്ള ഉപയോക്താക്കളിൽ നിന്ന് ബ്രൗസിംഗ് ചരിത്രമോ സ്‌ക്രീൻ ഉള്ളടക്കമോ ശേഖരിക്കുന്നില്ല.

ഈ നയത്തിലെ മാറ്റങ്ങൾ

ഈ നയം മാറുകയാണെങ്കിൽ, മുകളിലുള്ള തീയതി അപ്‌ഡേറ്റ് ചെയ്യും. ആപ്പ് റിലീസ് കുറിപ്പുകളിൽ മെറ്റീരിയൽ മാറ്റങ്ങളും വിവരിക്കും.

ബന്ധപ്പെടുക

സ്വകാര്യതാ ചോദ്യങ്ങൾക്കോ അഭ്യർത്ഥനകൾക്കോ ഞങ്ങൾക്ക് ഇമെയിൽ ചെയ്യുക. നിങ്ങൾ ഞങ്ങളെ ബന്ധപ്പെടുകയാണെങ്കിൽ, നിങ്ങളുടെ ഇമെയിൽ വിലാസവും നിങ്ങൾ അയയ്‌ക്കുന്ന വിവരങ്ങളും ഞങ്ങൾക്ക് ലഭിക്കും, അതിനാൽ ഞങ്ങൾക്ക് പ്രതികരിക്കാനാകും.
