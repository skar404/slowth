隱私權政策

最後更新：2026 年 9 月 20 日

Slowth 不會收集您的瀏覽記錄或螢幕內容。 App Store 應用程式沒有帳戶、分析、追蹤、廣告 SDK 或開發人員操作的後端。阻止和螢幕分析在您的裝置上運行。

Safari 封鎖

Slowth 是 Safari 扩展，带有适用于 iPhone 、 iPad 和 Mac 的配套应用程序。它在本地讀取支援的頁面以隱藏或重定向您選擇封鎖的內容。浏览历史记录、页面内容和阻止选择不会发送给开发人员。

即時阻止（測試版）— iPhone 與 iPad

如果启用此可选功能，Apple 的 ReplayKit 将在广播活动时提供屏幕帧。 Slowth 在您的裝置上使用 Core ML 來偵測選定的 Shorts 、 Reels 或故事，並要求 iOS 顯示 螢幕使用時間 盾牌。當監控處於活動狀態時，系統記錄指示器保持可見。

在正常使用 App Store 应用程序期间，不会保存或上传屏幕帧。音頻樣本未經處理。您可以使用錄製控制停止監視。開發人員擷取和上傳工具僅限於偵錯版本，並且在 App Store 應用程式中不可用。

在 Mac 上，Slowth 仅阻止 Safari 中的内容；它不会监视屏幕或阻止其他应用程序内的内容。

您的裝置上保留的內容

设置、每个站点模式、严格模式计时器、应用程序选择令牌和本地操作状态都存储在您的设备上。下載的阻止規則快取在本機。這些設定和規則不會發送給開發人員。

規則更新與網路請求

Safari 擴充功能定期透過 HTTPS 從 GitHub Gist 下載公共封鎖規則檔。每個人都可以使用相同的規則。该请求不包括浏览历史记录、页面内容、屏幕框架或您的应用程序选择。

GitHub 在提供文件時接收普通連接訊息，例如您的 IP 位址。適用其自己的隱私權政策。

螢幕使用時間 與 Family Controls — 僅 iOS

經您許可，Slowth 使用 Apple 的 Family Controls 和 Managed Settings 框架來阻止選定的應用程式。您的選擇由受隱私保護的令牌表示，儲存在本地並用於要求 iOS 應用程式阻止。

網站與外部服務

Slowth 網站透過 GitHub 頁面和 Cloudflare 提供服務。存取它會建立普通的 Web 請求，因此這些提供者會收到連接訊息，例如您的 IP 位址。打開其他外部鏈接受目的地隱私權政策的約束。此頁面上的語言連結無需 cookie 或 JavaScript 即可運作。

孩子們

Slowth 不會收集使用者（包括兒童）的瀏覽記錄或螢幕內容。

本政策的變更

如果此政策發生變化，頂部的日期將會更新。應用程式發行說明中還將描述重大變更。
