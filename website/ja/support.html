Slowth を設定し、境界を理解するか、 denis@malina.page までご連絡ください。

アプリ · iPhone および iPad のみ

アプリ内で Reels と Shorts をブロックします。

Instagram Reels 、 YouTube Shorts 、または Facebook 、 X (Twitter) およびその他のソーシャル アプリの短いビデオをブロックするには、アプリを選択して以下の手順に従います。 Snapchat 、 TikTok などのアプリやゲームを選択して、アプリ全体をブロックすることもできます。 を監視せずにブロッキングがどのように機能するかを確認してください。

  1. アプリ タブを開き、プロンプトが表示されたら スクリーンタイム アクセスを許可します。これにより、Slowth は iOS に選択したアプリをブロックするよう依頼できるようになります。録音は開始されません。
  2. Apple の スクリーンタイム ピッカーでブロックしたいアプリを選択します。カテゴリでは、現在そのカテゴリに含まれるアプリを選択します。アプリのみが保存され、Web サイトの選択は無視されます。さらにアプリをインストールした後、カテゴリーを再度選択してください。
  3. アプリをタップして、 ショートビデオ 、 ストーリー および ソフト ブロッキング のルールを選択します。新しい選択では、ソフト ブロック オフにより、両方のコンテンツ タイプがブロックされます。
  4. をタップして、[アプリ] タブで のモニタリングを開始し、必要に応じて Apple のブロードキャスト プロンプトで Slowth を選択し、開始を確認します。監視がアクティブになるまで待ってから、アプリに戻ります。
  5. 選択されたコンテンツが検出されると、 スクリーンタイム は アプリ全体 をシールドします。短い休憩のカウントダウンに従い、戻ったときにその内容を残します。
画面によって認識が異なります。 Slowth は、 Instagram 、 YouTube 、 Facebook 、 X (Twitter) などのソーシャル アプリ全体のショートビデオとストーリー画面を認識します。アプリのレイアウトが変化すると、認識がコンテンツを見逃したり、誤って通常の画面をブロックしたりする可能性があります。アプリを選択しただけでは監視は開始されません。

画面アクセスを理解する

ブロードキャストは、現在の画面の画像を提供します。これには、他のアプリや機密情報が含まれる可能性があります。アプリの選択により、どのアプリをブロックするかが制御されます。ブロードキャストに表示される内容を制限するものではありません。 App Store アプリでは、フレームはデバイス上で一時的に処理され、保存またはアップロードされません。音声は無視されます。

モニタリングを停止

Slowth に戻り、 をタップします。 の監視を停止し、システム プロンプトで確認します。 iOS 録画インジケーターを使用してブロードキャストを停止することもできます。インジケーターが停止していることを確認してください。監視を停止すると、以下で説明するようにアプリの保護が変更されます。 Safari 拡張機能はオフになりません。

Safari · iPhone 、 iPad & Mac

ブラウザから始めます。

iPhone および iPad

  1. Slowth をインストールして開きます。
  2. iOS 設定で、 アプリ → Safari → 拡張機能 → Slowth を開き、拡張機能を有効にします。古い iOS バージョンでは、Safari は設定に直接あります。
  3. Slowth でフィルタリングするサポート対象の Web サイトへのアクセスを許可します。サポートされているすべてのサイトをカバーしたい場合は、「すべての Web サイトを使用」→「許可」を選択します。
  4. Slowth の Safari 設定を開き、サイトごとにブロックするコンテンツを選択します。 Safari ですでに開いているページをリロードします。

Mac

  1. Safari → 設定 → 拡張機能 を開き、 Slowth を有効にします。
  2. Safari が要求した場合は、Web サイトへのアクセスを許可します。
  3. Slowth でサイトごとのオプションを選択し、ページをリロードします。

Safari には、スクリーンタイム 許可や画面ブロードキャストは必要ありません。 YouTube は Shorts コントロールを提供します。 Instagram および Facebook は、Reels およびフィード制御を提供します。 X は探索とトレンドをカバーします。サポートされている Web サイトを完全にブロックすることもできます。 TikTok にはサイト全体がブロックされます。

更新ルール を使用して、パブリック ブロック ルールへの変更を確認します。ルールの更新にはネットワーク接続が必要であり、厳密モードでは適用できません。

録画オフ時。

選択された保護されたアプリは通常、ブロードキャストが実行されないとブロックされます。録画を停止しても、それらのアプリに無制限にアクセスできるわけではありません。

ソフトブロッキング
アプリに対して有効になっている場合、 Slowth は、ユーザーが Slowth を離れた後、そのアプリを一時的に許可し、その後、そのアプリが使用されるときにブロックするように iOS に要求します。これはバックグラウンドオーディオに役立ちます。 Picture in Picture は引き続きブロックできます。無制限のモードではありません。
一時アクセス
コンテンツを許可すると、一時停止期間中、選択したグループ全体が開きます。録画しなくても動作します。アクセスが終了すると、ブロッキングが再開されますが、iOS ではブロックの適用が遅れる場合があります。

コンテンツ認識を使用するには、監視を再度開始してください。設定を変更できない場合は、Strict Mode が有効になっているかどうかを確認してください。

2種類の一時停止。

発見後の休息

Slowth がブロックすることを選択したコンテンツを検出すると、短いカウントダウンが表示され、アプリから少し離れることができます。これらの自動休符は 5 ～ 15 秒続き、葉は使用されません。カウントダウンが続いている間、Slowth を閉じることができます。戻ったときにブロックされたコンテンツをそのままにしておきます。そうしないと、別の休憩が始まる可能性があります。

リーフによる一時アクセス

iPhone および iPad では、アプリと Safari は 1 日あたり 3 回の一時停止を共有します。 コンテンツを許可 は、1 つのリーフを使用して、選択したグループ全体でブロックされたコンテンツを一時的に許可します。 [ 設定] → [一時停止期間 ] で、新しい一時停止に 30 秒、1 分、または 3 分を選択します。タイマーは残りのアクセスを示します。 再びブロック は一時的なアクセスを早期に終了し、ブロックを復元します。使用済みのリーフは返金されません。

未使用の葉は、その日が終了すると保存された報酬カウントになります。保存されたリーフは追加のアクセスではありません。共有一時停止は実験的なものであり、iOS により制限の復元が遅れる可能性があります。一時的なアクセスには画面ブロードキャストは必要ありません。

明確な制限のあるストリクト モード。

厳格モード ロックにより、 24 時間 の制限が有効になりました。タイマーは、アプリを閉じてデバイスを再起動しても存続します。 Slowth 内で早期に終了することはできません。

  • 有効な制限を弱めることはできません。制限を追加することはできますが、ロック中にサイト全体のブロックを有効にすることはできません。
  • 厳密モードがアクティブな間、ルールの更新はロックされます。
  • iPhone および iPad では、開始前に Strict モード での一時停止を許可するかどうかを決定します。一時停止が禁止されている場合、ロック中に一時停止を再度有効にすることはできません。

Strict モードは個人的なコミットメント ツールです。デバイスの改ざん防止や、アプリの削除やシステム権限の変更など、 Slowth 以外のすべての変更を防止するものではありません。有効にする前に設定を確認してください。

何かがおかしいですか?

Shorts または Reels は依然として Safari に表示されます

拡張機能が有効になっていること、その Web サイトに対する権限があること、および関連するブロック オプションが有効になっていることを確認してください。ページをリロードします。厳密モード以外では、ルールを更新して再試行してください。 Web サイトのレイアウトが変更されます。それでも失敗する場合は、サイト名、OS バージョン、再現手順を送信してください。

アプリを開くとすぐにブロックされます

Slowth で監視状態を確認します。アクティブなブロードキャストがなければ、選択された保護されたアプリは通常ブロックされます。コンテンツ検出の監視を開始するか、可能な場合は一時的なアクセスの一時停止を使用します。また、検出レストがまだアクティブであるかどうかも確認してください。

モニタリングが停止する、または開始されない

Slowth に戻り、Apple のプロンプトを通じて監視を再度開始します。システム録画インジケーターとスクリーンタイム許可を確認してください。 iOS は画面ブロードキャストを中断できます。 Slowth は、サイレントに再起動することはできません。繰り返し中断された場合は、デバイスと OS のバージョンを報告してください。

Slowth が間違った画面をブロックするか、コンテンツを見逃します

認識は不完全です。選択したアプリのコンテンツ ルールと、そのコンテンツがサポートされているかどうかを確認します。アプリのフィードバック オプションまたは電子メールで何が起こったかを報告できます。機密性の高い画面コンテンツを送信しないでください。アプリ、画面、手順の説明は、始めるのに役立ちます。

一時停止は終了しましたが、アクセスはすぐには変更されませんでした

一時停止タイマーとシステム アプリのブロック画面は別個です: iOS は制限の復元を遅らせる可能性があります。 Slowth を再度開いて、現在の状態を確認します。問題を報告する際には、一時停止期間と監視が実行されていたかどうかを含めてください。

設定がロックされているか、アプリが見つかりません

Strict Mode タイマーを確認し、システム ピッカーでの選択を確認します。システム ピッカーからはアプリのみが保存されます。ウェブサイトは無視されます。アプリをインストールする前にカテゴリを選択した場合は、再度カテゴリを選択します。

さらにサポートが必要ですか?

何が起こったのか教えてください。

denis@malina.page または にメールを送信して、GitHub 問題 を開きます。 Slowth のバージョン、デバイスと OS のバージョン、再現手順、予想した内容を含めます。 Safari で発生したか、アプリ内で発生したか、監視、一時停止、または厳密モードがアクティブだったかどうかについて言及します。

画面アクセスとネットワーク リクエストの詳細については、 プライバシー ポリシー を参照してください。
