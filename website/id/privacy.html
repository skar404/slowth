Kebijakan Privasi

Terakhir diperbarui: 20 September 2026

Slowth tidak mengumpulkan riwayat penelusuran atau konten layar Anda. Aplikasi App Store tidak memiliki akun, analitik, pelacakan, SDK periklanan, atau backend yang dioperasikan pengembang. Pemblokiran dan analisis layar dijalankan di perangkat Anda.

pemblokiran Safari

Slowth adalah ekstensi Safari dengan aplikasi pendamping untuk iPhone, iPad, dan Mac. Bunyinya halaman yang didukung secara lokal untuk menyembunyikan atau mengalihkan konten yang Anda pilih untuk diblokir. Riwayat penjelajahan, konten halaman, dan pilihan pemblokiran tidak dikirimkan ke pengembang.

Pemblokiran Waktu Nyata (Beta) — iPhone dan iPad

Jika Anda mengaktifkan fitur opsional ini, ReplayKit Apple menyediakan bingkai layar saat siaran aktif. Slowth menggunakan Core ML di perangkat Anda untuk mendeteksi Shorts, Reels, atau Stories yang dipilih dan meminta iOS untuk menampilkan perisai Screen Time. Indikator perekaman sistem tetap terlihat saat pemantauan aktif.

Bingkai layar tidak disimpan atau diunggah selama penggunaan normal aplikasi App Store. Sampel audio tidak diproses. Anda dapat menghentikan pemantauan menggunakan kontrol perekaman. Alat pengambilan dan pengunggahan pengembang dibatasi untuk debug build dan tidak tersedia di aplikasi App Store.

Pada Mac, Slowth memblokir konten hanya di Safari ; itu tidak memantau layar atau memblokir konten di dalam aplikasi lain.

Apa yang tersisa di perangkat Anda

Pengaturan, mode per situs, pengatur waktu Mode Ketat, token pemilihan aplikasi, dan status pengoperasian lokal disimpan di perangkat Anda. Aturan pemblokiran yang diunduh di-cache secara lokal. Pengaturan dan aturan ini tidak dikirimkan ke pengembang.

Pembaruan aturan dan permintaan jaringan

Ekstensi Safari secara berkala mengunduh file aturan pemblokiran publik dari GitHub Gist melalui HTTPS. Aturan yang sama tersedia untuk semua orang. Permintaan tersebut tidak mencakup riwayat penjelajahan, konten halaman, bingkai layar, atau pilihan aplikasi Anda.

GitHub menerima informasi koneksi biasa, seperti alamat IP Anda, saat menyajikan file. Kebijakan privasinya sendiri berlaku.

Screen Time dan Family Controls — hanya iOS

Dengan izin Anda, Slowth menggunakan kerangka kerja Family Controls dan Managed Settings Apple untuk memblokir aplikasi yang dipilih. Pilihan Anda diwakili oleh token yang dilindungi privasi, disimpan secara lokal dan digunakan untuk meminta iOS menerapkan pemblokiran aplikasi.

Situs web dan layanan eksternal

Situs web Slowth disajikan melalui Halaman GitHub dan Cloudflare. Mengunjunginya menciptakan permintaan web biasa, sehingga penyedia tersebut menerima informasi koneksi seperti alamat IP Anda. Pembukaan tautan eksternal lainnya diatur oleh kebijakan privasi tujuan. Tautan bahasa di halaman ini berfungsi tanpa cookie atau JavaScript.

Anak-anak

Slowth tidak mengumpulkan riwayat penelusuran atau konten layar dari pengguna, termasuk anak-anak.

Perubahan pada kebijakan ini

Jika kebijakan ini berubah, tanggal di atas akan diperbarui. Perubahan material juga akan dijelaskan dalam catatan rilis aplikasi.

  • GitHub pernyataan privasi
  • Cloudflare kebijakan privasi
