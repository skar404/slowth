Dasar Privasi

Kemas kini terakhir: 20 September 2026

Slowth tidak mengumpul sejarah penyemakan imbas atau kandungan skrin anda. Apl App Store tidak mempunyai akaun, analitis, penjejakan, SDK pengiklanan atau bahagian belakang yang dikendalikan oleh pembangun. Penyekatan dan analisis skrin dijalankan pada peranti anda.

Safari menyekat

Slowth ialah sambungan Safari dengan apl pendamping untuk iPhone, iPad dan Mac. Ia membaca halaman yang disokong secara setempat untuk menyembunyikan atau mengubah hala kandungan yang anda pilih untuk disekat. Sejarah penyemakan imbas, kandungan halaman dan pilihan menyekat tidak dihantar kepada pembangun.

Penyekatan Masa Nyata (Beta) — iPhone dan iPad

Jika anda mendayakan ciri pilihan ini, ReplayKit Apple membekalkan bingkai skrin semasa siaran aktif. Slowth menggunakan Core ML pada peranti anda untuk mengesan Shorts, Reels atau Stories yang dipilih dan meminta iOS menunjukkan perisai Screen Time. Penunjuk rakaman sistem kekal kelihatan semasa pemantauan aktif.

Bingkai skrin tidak disimpan atau dimuat naik semasa penggunaan biasa apl App Store. Sampel audio tidak diproses. Anda boleh menghentikan pemantauan menggunakan kawalan rakaman. Alat tangkapan dan muat naik pembangun adalah terhad kepada binaan nyahpepijat dan tidak tersedia dalam apl App Store.

Pada Mac, Slowth menyekat kandungan hanya dalam Safari ; ia tidak memantau skrin atau menyekat kandungan dalam aplikasi lain.

Perkara yang kekal pada peranti anda

Tetapan, mod setiap tapak, pemasa Mod Ketat, token pemilihan aplikasi dan status pengendalian setempat disimpan pada peranti anda. Peraturan penyekatan yang dimuat turun dicache secara setempat. Tetapan dan peraturan ini tidak dihantar kepada pembangun.

Kemas kini peraturan dan permintaan rangkaian

Sambungan Safari memuat turun fail peraturan sekatan awam secara berkala daripada GitHub Gist melalui HTTPS. Peraturan yang sama tersedia untuk semua orang. Permintaan itu tidak termasuk sejarah penyemakan imbas, kandungan halaman, bingkai skrin atau pilihan apl anda.

GitHub menerima maklumat sambungan biasa, seperti alamat IP anda, semasa menyampaikan fail. Dasar privasinya sendiri terpakai.

Screen Time dan Family Controls — iOS sahaja

Dengan kebenaran anda, Slowth menggunakan rangka kerja Family Controls dan Managed Settings Apple untuk menyekat apl terpilih. Pilihan anda diwakili oleh token yang dilindungi privasi, disimpan secara setempat dan digunakan untuk meminta iOS menggunakan penyekatan apl.

Laman web dan perkhidmatan luaran

Laman web Slowth disediakan melalui GitHub Pages dan Cloudflare. Melawatnya mewujudkan permintaan web biasa, jadi pembekal tersebut menerima maklumat sambungan seperti alamat IP anda. Membuka pautan luaran lain dikawal oleh dasar privasi destinasi. Pautan bahasa pada halaman ini berfungsi tanpa kuki atau JavaScript.

Kanak-kanak

Slowth tidak mengumpul sejarah penyemakan imbas atau kandungan skrin daripada pengguna, termasuk kanak-kanak.

Perubahan pada dasar ini

Jika dasar ini berubah, tarikh di bahagian atas akan dikemas kini. Perubahan bahan juga akan diterangkan dalam nota keluaran apl.

  • GitHub pernyataan privasi
  • Cloudflare dasar privasi
