गोपनीयता धोरण

शेवटचे अपडेट: 20 सप्टेंबर 2026

Slowth तुमचा ब्राउझिंग इतिहास किंवा स्क्रीन सामग्री संकलित करत नाही. App Store ॲपमध्ये कोणतेही खाते, विश्लेषण, ट्रॅकिंग, जाहिरात SDK किंवा डेव्हलपर-ऑपरेट केलेले बॅकएंड नाही. तुमच्या डिव्हाइसवर ब्लॉकिंग आणि स्क्रीन विश्लेषण चालते.

Safari अवरोधित करणे

Slowth हे iPhone, iPad आणि Mac साठी सहचर ॲपसह Safari विस्तार आहे. तुम्ही ब्लॉक करण्यासाठी निवडलेली सामग्री लपवण्यासाठी किंवा पुनर्निर्देशित करण्यासाठी ते स्थानिक पातळीवर समर्थित पृष्ठे वाचते. ब्राउझिंग इतिहास, पृष्ठ सामग्री आणि अवरोधित करण्याच्या निवडी विकसकाला पाठवल्या जात नाहीत.

रिअल-टाइम ब्लॉकिंग (बीटा) — iPhone आणि iPad

तुम्ही हे पर्यायी वैशिष्ट्य सक्षम केल्यास, Apple चे ReplayKit प्रसारण सक्रिय असताना स्क्रीन फ्रेम पुरवते. Slowth निवडलेल्या Shorts, Reels, किंवा कथा शोधण्यासाठी तुमच्या डिव्हाइसवर Core ML वापरते आणि iOS ला Screen Time शील्ड दाखवायला सांगते. मॉनिटरिंग सक्रिय असताना सिस्टम रेकॉर्डिंग इंडिकेटर दृश्यमान राहतो.

App Store ॲपच्या सामान्य वापरादरम्यान स्क्रीन फ्रेम सेव्ह किंवा अपलोड केल्या जात नाहीत. ऑडिओ नमुन्यांची प्रक्रिया केली जात नाही. तुम्ही रेकॉर्डिंग नियंत्रणे वापरून निरीक्षण थांबवू शकता. विकसक कॅप्चर आणि अपलोड साधने डीबग बिल्डसाठी प्रतिबंधित आहेत आणि App Store ॲपमध्ये उपलब्ध नाहीत.

Mac वर, Slowth फक्त Safari मध्ये सामग्री अवरोधित करते; ते स्क्रीनचे निरीक्षण करत नाही किंवा इतर ॲप्समधील सामग्री ब्लॉक करत नाही.

तुमच्या डिव्हाइसवर काय राहते

सेटिंग्ज, प्रति-साइट मोड, कठोर मोड टाइमर, ॲप-निवड टोकन आणि स्थानिक ऑपरेटिंग स्थिती तुमच्या डिव्हाइसवर संग्रहित आहेत. डाउनलोड केलेले ब्लॉकिंग नियम स्थानिक पातळीवर कॅश केले जातात. या सेटिंग्ज आणि नियम विकासकाला पाठवले जात नाहीत.

नियम अद्यतने आणि नेटवर्क विनंत्या

Safari विस्तार वेळोवेळी HTTPS वर GitHub Gist वरून सार्वजनिक ब्लॉकिंग-नियम फाइल डाउनलोड करतो. समान नियम सर्वांसाठी उपलब्ध आहेत. विनंतीमध्ये ब्राउझिंग इतिहास, पृष्ठ सामग्री, स्क्रीन फ्रेम किंवा आपल्या ॲप निवडीचा समावेश नाही.

फाईल सर्व्ह करताना GitHub ला सामान्य कनेक्शन माहिती मिळते, जसे की तुमचा IP पत्ता. त्याचे स्वतःचे गोपनीयता धोरण लागू होते.

Screen Time आणि Family Controls — फक्त iOS

तुमच्या परवानगीने, Slowth निवडक ॲप्स ब्लॉक करण्यासाठी Apple चे Family Controls आणि Managed Settings फ्रेमवर्क वापरते. तुमच्या निवडी गोपनीयते-संरक्षित टोकनद्वारे दर्शविले जातात, स्थानिकरित्या संग्रहित केले जातात आणि ॲप ब्लॉकिंग लागू करण्यासाठी iOS ला विचारण्यासाठी वापरले जातात.

वेबसाइट आणि बाह्य सेवा

Slowth वेबसाइट GitHub पृष्ठे आणि Cloudflare द्वारे दिली जाते. याला भेट दिल्याने सामान्य वेब विनंत्या तयार होतात, त्यामुळे त्या प्रदात्याना तुमचा IP पत्ता सारखी कनेक्शन माहिती मिळते. इतर बाह्य दुवे उघडणे गंतव्यस्थानाच्या गोपनीयता धोरणाद्वारे नियंत्रित केले जाते. या पृष्ठावरील भाषा दुवे कुकीज किंवा JavaScript शिवाय कार्य करतात.

मुले

Slowth मुलांसह वापरकर्त्यांकडून ब्राउझिंग इतिहास किंवा स्क्रीन सामग्री संकलित करत नाही.

या धोरणात बदल

हे धोरण बदलल्यास, शीर्षस्थानी तारीख अपडेट केली जाईल. ॲप रिलीझ नोट्समध्ये सामग्री बदलांचे वर्णन देखील केले जाईल.

  • GitHub गोपनीयता विधान
  • Cloudflare गोपनीयता धोरण

संपर्क करा

गोपनीयता प्रश्न किंवा विनंत्यांसाठी, आम्हाला ईमेल करा. आपण आमच्याशी संपर्क साधल्यास, आम्हाला तुमचा ईमेल पत्ता आणि तुम्ही पाठवलेली माहिती प्राप्त होईल जेणेकरून आम्ही प्रतिसाद देऊ शकू.
